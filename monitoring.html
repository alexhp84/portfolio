Monitoring & Alerting Demo

A self-built observability stack with synthetic data for safe portfolio demonstrations.

What the demo covers

A self-built monitoring and alerting stack running in my home environment, assembled with Docker Compose. Prometheus evaluates metrics and alert rules, Alertmanager routes notifications to Alerta, PostgreSQL stores Alerta data, Grafana provides dashboards, and Loki/Promtail collect logs. The portfolio view uses dummy metrics and synthetic alerts so real home infrastructure details are not exposed.

Metrics & dashboards

Prometheus scrapes a synthetic exporter; Grafana is used to explore and visualise the resulting metrics.
